# ⚙️ Пошаговая настройка

## 1️⃣ Создание Telegram бота

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Введите название: `Мастера TJ`
4. Введите username: `masteratj_bot` (или другой доступный)
5. Скопируйте токен (выглядит так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

## 2️⃣ Получение вашего Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Нажмите `/start`
3. Бот отправит ваш ID (например: `123456789`)

## 3️⃣ Настройка проекта

```bash
# Клонирование (если еще не сделано)
git clone <repository-url>
cd mastera-tj-bot

# Установка зависимостей
npm install

# Создание .env файла
cp .env.example .env
```

Откройте `.env` и заполните:

```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_TELEGRAM_ID=123456789
RESPONSE_PRICE=5
```

## 4️⃣ Инициализация базы данных

```bash
npm run init-db
```

Вы увидите:
```
✅ Database initialized successfully
📊 Categories: 8
🏙 Cities: 8
```

## 5️⃣ Запуск бота

```bash
npm start
```

Должно появиться:
```
✅ Bot started successfully
📊 Database ready
🚀 Mastera TJ is running...
```

## 6️⃣ Тестирование

### Как клиент

1. Откройте вашего бота в Telegram
2. Нажмите `/start`
3. Выберите "📝 Создать заявку"
4. Заполните форму

### Как мастер

1. Отправьте команду `/register`
2. Заполните регистрационную форму
3. Ожидайте одобрения админа

### Как администратор

1. Отправьте команду `/admin`
2. Выберите "✅ Одобрить мастеров"
3. Одобрите тестового мастера

## 7️⃣ Тестирование полного цикла

1. **Админ:** одобрите тестового мастера
2. **Админ:** пополните баланс мастера:
   ```
   /addbalance TELEGRAM_ID 100
   ```
3. **Клиент:** создайте заявку
4. **Мастер:** получит уведомление о заявке
5. **Мастер:** нажмите "Откликнуться"
6. **Клиент:** получит контакт мастера

## 🔧 Настройки

### Изменение цены отклика

В `.env`:
```env
RESPONSE_PRICE=10
```

### Добавление категорий

Отредактируйте `src/db/schema.js`:
```javascript
const categories = [
  'Сантехник',
  'Электрик',
  'Ваша новая категория'
];
```

Пересоздайте БД:
```bash
rm mastera_tj.db
npm run init-db
```

### Добавление городов

Аналогично в `src/db/schema.js`:
```javascript
const cities = [
  'Душанбе',
  'Худжанд',
  'Ваш новый город'
];
```

## ❓ Часто задаваемые вопросы

### Бот не отвечает?

1. Проверьте, запущен ли процесс: `ps aux | grep node`
2. Проверьте логи: `npm start` (смотрите ошибки)
3. Проверьте токен в `.env`

### "Error: 401: Unauthorized"?

Неверный BOT_TOKEN. Проверьте токен в `.env`

### База данных не создается?

```bash
# Убедитесь, что sqlite установлен
npm install better-sqlite3

# Пересоздайте БД
rm mastera_tj.db
npm run init-db
```

### Как добавить второго админа?

В коде пока поддерживается только один админ через `ADMIN_TELEGRAM_ID`.
Для нескольких админов нужно модифицировать `src/handlers/admin.js`:

```javascript
const ADMIN_IDS = [123456789, 987654321];

export const isAdmin = (telegramId) => {
  return ADMIN_IDS.includes(telegramId);
};
```
