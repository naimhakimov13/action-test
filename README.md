# 🔧 Мастера TJ

Telegram-бот для поиска и заказа услуг мастеров в Таджикистане.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка окружения

Создайте файл `.env`:

```bash
cp .env.example .env
```

Заполните переменные:

```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_TELEGRAM_ID=your_admin_telegram_id
RESPONSE_PRICE=5
```

### 3. Инициализация базы данных

```bash
npm run init-db
```

### 4. Запуск бота

```bash
npm start
```

Для разработки с авто-перезагрузкой:

```bash
npm run dev
```

## 📋 Функционал

- 🔍 Поиск мастеров

- ✅ Одобрение мастеров
- 📊 Статистика платформы

- 💰 Пополнение балансов

## 🗄 База данных

SQLite база с таблицами:
- `users` - пользователи
- `masters` - профили мастеров
- `categories` - категории услуг
- `cities` - города
- `requests` - заявки клиентов
- `responses` - отклики мастеров
- `transactions` - финансовые операции

## 💰 Монетизация

- Отклик на заявку: 5 сомони (настраивается)
- Ручное пополнение через админа
- История транзакций

## 🛠 Технологии

- Node.js
- Telegraf (Telegram Bot API)
- SQLite (better-sqlite3)
- dotenv

## 📝 Команды бота

### Для всех

- `/start` - Начало работы

### Для мастеров

- `/register` - Регистрация как мастер

### Для администраторов

- `/admin` - Админ-панель
- `/addbalance <telegram_id> <сумма>` - Пополнить баланс

## 🔐 Получение токена бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен в `.env`

## 📱 Получение Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Отправьте `/start`
3. Скопируйте ваш ID в `.env` как `ADMIN_TELEGRAM_ID`

## 🔄 Процесс создания заявки

1. Клиент выбирает категорию
2. Указывает город
3. Описывает проблему (+ фото опционально)
4. Указывает телефон
5. Подтверждает заявку
6. Мастера получают уведомление
7. Мастер откликается (−5 сом)
8. Клиент получает контакт мастера

## 🎯 Процесс регистрации мастера

1. Команда `/register`
2. Указывает ФИО
3. Указывает телефон
4. Выбирает категорию
5. Выбирает город
6. Описывает опыт
7. Отправка на модерацию
8. Админ одобряет/отклоняет
9. Мастер получает уведомление
